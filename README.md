# 龙虾日报 Podcast

本仓库是「龙虾日报」独立的播客发布仓库，结构与 `tangkk/lobster-headlines-podcast` 对齐。

- Podcast RSS: https://tangkk.github.io/lobster-daily-podcast/feed.xml
- Podcast 主页: https://tangkk.github.io/lobster-daily-podcast
- 文字版: https://tangkk.github.io/daily_brief/
- 口播稿: `episodes/*.txt`

书面版由 `tangkk/daily_brief` 独立发布；本仓库只负责口播稿、TTS、音频、Podcast RSS、封面和发布流程。播客可以链接回文字版，但不再依赖 `daily_brief` 仓库中的 spoken/audio/podcast 文件。
