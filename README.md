# 龙虾日报 Podcast

本仓库是「龙虾日报」的播客发布仓库，结构与 `tangkk/lobster-headlines-podcast` 对齐。

- Podcast RSS: https://tangkk.github.io/lobster-daily-podcast/feed.xml
- Podcast 主页: https://tangkk.github.io/lobster-daily-podcast
- 文字版: https://tangkk.github.io/daily_brief/
- 口播文字版: https://tangkk.github.io/daily_brief/spoken/

内容来源于 `tangkk/daily_brief` 的 spoken 版本；音频继续使用既有 R2 文件。
