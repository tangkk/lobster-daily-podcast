龙虾日报，2026年11月18日。

英伟达公布新财季收入一千一百五十八亿美元，数据中心业务继续高速增长，并预计下一季度总收入约一千三百亿美元。微软推出自己的编程模型，百度披露人工智能云收入增长九成以上。美国十月零售增速放慢，工业总产出下降；这些数据让算力投资与更广泛的实体需求形成鲜明对照。今天我们先看已确认的收入和利润，再看模型竞争、消费和生产。

今日数字：一千零七十六亿美元，这是英伟达最新财季的数据中心收入，同比增长百分之一百一十。它说明芯片供应商确实收到了大规模订单，云服务商和最终用户能否持续收回投资，还需要各自的财务数据证明。

英伟达截至十月二十五日的第三财季收入一千一百五十八亿美元，比上年同期增长百分之一百零三，比上一季度增长百分之二十。其中数据中心收入一千零七十六亿美元，环比增长百分之二十一。按美国通用会计准则计算，毛利率为百分之七十四点八，净利润六百五十三亿美元。财报列出的季度自由现金流约四百三十八亿美元。对人工智能投资链条而言，这提供了新的现金证据：上游设备供应商的交付和利润仍在迅速扩大。不过，这笔收入是供应商的销售，不能直接当作云客户的利润，也不能证明所有新建数据中心已经充分利用。

公司预计下一财季收入约一千三百亿美元，允许上下浮动百分之三，并称新的 Vera Rubin 机架系统已经开始出货。下一财季包含额外一周，因此指引与本季不能按普通等长季度直接比较。接下来要观察实际交货、云端利用率、租赁价格，以及购买这些设备的企业是否能从终端客户取得足够回款。前一美国交易日的股市在财报公布之前收盘，不能把当天跌幅解释成投资者对这份财报的反应。

第二条是微软。公司在 Ignite 大会上宣布自研编程模型 Code 2 和 Code 2 Flash，已经在 GitHub Copilot 和 Foundry 提供使用。前者面向复杂代码工作，后者面向频繁的小任务。微软还宣布 Decision 1.1 模型正式开放，并称已有四千多家客户用过它。微软现在同时提供合作伙伴模型与自家模型，企业可以按任务、价格和质量选择。公司宣称的新模型成本优势，需要独立测试才能判断；四千家客户的使用数也没有对应的付费收入。后续值得看的是开发者实际选择、每项任务的有效成本，以及企业合同是否扩大。

中国人工智能市场出现两组新读数。百度最新季度的人工智能云基础设施收入为八十二亿元人民币，同比增长百分之九十四；其中图形处理器云收入同比增长百分之一百九十一。公司称，千帆平台外部客户使用模型所产生的 token 收入同比增加十一倍以上，预付款和长期合同也在增加。这比单纯发布新功能更接近真实付费需求。不过百度没有披露这项 token 收入的绝对金额，而且人工智能应用业务收入约二十六亿元，同比大致持平。云基础设施和终端应用的商业兑现仍有差异。

美国十月零售和餐饮销售额为七千四百八十二亿美元，环比增长百分之零点二，低于九月的百分之零点八。零售数据没有扣除价格变化，月度涨幅也落在官方抽样误差范围内，因此还不能断言实际消费已经萎缩。美国十月工业总产出环比下降百分之零点四；制造业产出却增长百分之零点三。公用事业和采矿业的下降拉低了总数。工业产能利用率降至百分之七十六点四，低于长期平均水平。两份统计共同提醒我们，科技设备收入的高速增长并不代表每个实体部门同步走强。

市场方面，最新完成的美国交易日，标普五百下跌约百分之一，道指下跌约百分之一点六，纳斯达克下跌约百分之零点七。上述收盘先于英伟达财报。美国先进芯片境外远程使用规则目前安排在十九日刊登于联邦公报；在刊登前，正式生效和过渡时间仍须以最终文本核对。

今天的核心观察是两条现金链：英伟达已经确认巨额收入和自由现金流，百度也报告了云服务客户使用增长；购买算力的企业能否在合同期内获得足够的实际收益，仍要看利用率、毛利率和回款。接下来关注财报之后的完整交易日、云客户披露，以及美国经济数据的修订。
